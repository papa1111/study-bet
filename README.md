# 공부 내기판

친구들끼리 공부시간으로 내기하는 사이트.

- 주소: https://papa1111.github.io/study-bet/
- Firebase 프로젝트: study-bet-dd58b

## 규칙
- 매일 자정(한국시간) 기준 공부시간 꼴찌 +500원 (공동 꼴찌면 둘 다)
- 탭 벗어나거나 화면 끄면 타이머 자동 일시정지
- 구라 신고: 3명 이상, 본인 빼고 과반 동의 시 세션 시간 삭제, 1인 하루 3회, 해명 한 줄
- 채팅은 버튼만, 최근 100개, 같은 버튼 3초 쿨타임

## 파일 수정 후
- `firestore.rules`를 바꾸면 Firebase 콘솔 > Firestore > 규칙에 다시 붙여넣고 게시
